Laboratório HTTP vs HTTPS

Servidor nginx com o certificado da AC-Raiz-Empresa (Workshop 07).

Porta 80 — HTTP (SEM criptografia)

Abra o documento secreto em claro: http://172.30.234.55/secreto/documento-secreto.txt

Peça a senha ao professor. No sniffing, tudo aparece legível.

Porta 443 — HTTPS (criptografado)

Abra o mesmo documento com TLS: https://servidor.local/secreto/documento-secreto.txt

O navegador vai reclamar do certificado (nossa CA não é pública) — aceite o aviso ou importe o ca.crt.

No sniffing, só aparecem bytes criptografados.
